# Banking Data Analysis & Power BI Dashboard

This project focuses on **Banking Data Analysis and Business Intelligence** using Python, Pandas, NumPy, Matplotlib, Seaborn, and Power BI.

The project performs **Exploratory Data Analysis (EDA)** on banking customer data to understand customer demographics, income levels, savings, deposits, loans, credit card balances, business lending, and other financial attributes.

### 🔍 Key Analysis Performed

* Data loading and dataset exploration
* Data shape and information analysis
* Descriptive statistical analysis
* Missing-value analysis
* Income Band categorization into **Low, Mid, and High**
* Categorical feature analysis
* Numerical feature distribution analysis
* Correlation matrix and heatmap
* Relationship analysis using regression plots
* Analysis of banking deposits, savings, loans, and lending behavior
* Business-oriented insights from customer financial data

### 📊 Power BI Dashboard

A **Power BI Banking Dashboard** is also included to provide an interactive view of important banking metrics and customer-related information.

### 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Power BI

### 📈 Key Insights

The analysis explores relationships between:

* Bank Deposits and Saving Accounts
* Checking Accounts and Saving Accounts
* Age and Superannuation Savings
* Estimated Income and Checking Accounts
* Bank Loans and Credit Card Balance
* Business Lending and Bank Loans
* Properties Owned and other financial variables

This project demonstrates practical skills in **Data Cleaning, Exploratory Data Analysis, Data Visualization, Business Analytics, and Power BI Dashboard Development**.
